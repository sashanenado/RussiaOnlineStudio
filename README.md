# Russia Online Studio

Локальная мастерская для помощника GTA RP Arbat.

## В текущей версии

- `web/` — локальная Studio MVP: библиотека статей, конструктор памяток, предпросмотр, импорт/экспорт JSON.
- `data/` — начальные данные и совместимые файлы.
- `.github/workflows/` — автоматическая сборка ZIP артефакта.

## План Windows-поставки

- `Studio.exe` — управление базой, профилями, панелями и настройками.
- `Overlay.exe` — независимые игровые окна.
- Общая переносимая папка `Data`.

**Ограничение MVP:** веб-версия не может создавать прозрачные always-on-top окна поверх GTA и перехватывать глобальные F8–F11. Это отдельная задача Windows Overlay.
